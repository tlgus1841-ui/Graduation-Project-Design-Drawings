## 🎯 2. AI 하네스 엔지니어링(AI Harness Engineering) 개요

### 2.1 하네스 엔지니어링의 정의
**하네스(Harness)**란 고성능 엔진이나 소프트웨어가 극한의 환경에서도 안정적으로 구동될 수 있도록 감싸는 **제어·측정·안전 프레임워크(Testbed, Guardrails, Sensors)**를 뜻합니다.
본 프로젝트에서는 AI 기반 개발(바이브 코딩)과 SDN 자율 방어 시스템의 신뢰성을 극대화하기 위해 **듀얼 하네스(Dual Harness)** 체계를 구축합니다.

## 🛠️ 3. 세부 설계: [축 1] AI 개발 지원 하네스 (Development Harness)

### 3.1 Context & Contract Harness (컨텍스트 및 인터페이스 가드레일)
AI 코딩 에이전트(Antigravity, Cursor 등)가 코드를 생성할 때 아키텍처 규칙과 통신 규격을 위반하지 않도록 사전에 강제하는 하네스입니다.

1. **Golden Version Matrix 정적 주입:**
   - `.cursorrules` 및 시스템 프롬프트에 Python 3.8 Docker(Ryu), Python 3.10(AI/Web), OpenFlow 1.3 스펙 고정.
   - Ryu 내부에서 `time.sleep()`, Scikit-learn 추론 등 CPU-bound 동기 연산 작성을 정적 규칙으로 차단.
2. **Pydantic v2 Contract-First 스키마 확정:**
   - Redis IPC 채널(`sdn:stats:port`, `sdn:anomaly:alert`, `sdn:control:command`) 메시지 규격을 `harness/contracts/`에 단일 진실 공급원(SSOT)으로 정의.

### 3.2 Verification Harness (초고속 검증 러너)
1. **Mock IPC Bus (`tests/harness/test_mock_ipc.py`):**
   - Mininet이나 Redis 서버 없이도 메모리 상에서 메시지 발행/구독과 직렬화/역직렬화를 0.1초 내로 단위 검증.
2. **Headless Topology Simulator (`tests/harness/test_headless_topology.py`):**
   - 가상 환경에서 5-스위치 다이아몬드 토폴로지를 에뮬레이션하여 OpenFlow `OFPFC_ADD` 다중 홉 우회 규칙이 올바르게 생성되는지 검증.

## 🛡️ 4. 세부 설계: [축 2] AI 런타임 & 안전 하네스 (Runtime Defense Harness)

### 4.1 Traffic & Evaluation Harness (유재민 / Domain Dev & QA 주관)
1. **Scapy 트래픽 생성 및 검증기:**
   - 정상 트래픽: Poisson 분포 기반 웹 트래픽(BPP 500~1400B).
   - 공격 트래픽: 랜덤 스푸핑 IP 기반 SYN Flooding (BPP 54~74B), 초당 1,000~5,000 PPS 주입.
   - Checksum 누락 방지 코드 자동 검증(`del pkt[IP].chksum`).
2. **Automated Anomaly Benchmark Suite:**
   - 특징 추출 지연시간($\le 5\text{ms}$), 모델 추론 지연시간($\le 10\text{ms}$), 전체 E2E 방어 반응시간($\le 100\text{ms}$) 프로파일링.
   - 모델의 F1-Score, 정상 트래픽 오탐률(False Positive Rate $< 1.0\%$)을 산출하여 데이터셋 저장.

### 4.2 Safety Guardrails & Circuit Breaker (박시현 / Tech Lead 주관)
1. **Critical Port Whitelist Guard:**
   - 관리자 제어 포트, 핵심 서버 포트(`h_server`), 스위치 간 트렁크 링크 포트에 대해 AI가 Drop 결정을 내려도 하네스가 차단 명령을 가로채고 경고 로그만 남김.
2. **FSM 기반 라우팅 플래핑(Flapping) 방지기:**
   - 단순 타임아웃에 의한 주기적 플래핑 차단:  
     `NORMAL` $\to$ `ATTACK_DETECTED` $\to$ `MITIGATED` $\to$ `COOLDOWN_VERIFY` $\to$ `NORMAL`
   - 공격 소멸이 10초 이상 지속 확인된 경우에만 점진적 롤백 실행.
3. **Fail-Safe Circuit Breaker:**
   - AI Worker 다운 또는 Redis 단절 감지 시 5초 내 안전 모드로 컨트롤러 전환.
